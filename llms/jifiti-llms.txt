# Jifiti

> Jifiti is a white-labeled embedded-lending platform. Banks and lenders use it to
> place their own loan programs at any point of sale — in store, online, or via call
> center — so merchants can offer consumer and business financing from lenders their
> customers already trust. The platform covers BNPL and split payments, one-time
> installment loans, revolving lines of credit, B2B financing, disbursement and
> settlement (including virtual cards), and merchant/lender reporting portals.

Generated 2026-08-27 by the API Evangelist enrichment pipeline from apis.yml and the
artifacts in this repository. Jifiti does not publish an llms.txt of its own —
https://www.jifiti.com/llms.txt returns 404, and the /llms.txt paths on the two
developer hubs redirect to a password gate.

## Important: what is and is not publicly available

Jifiti markets two APIs but publishes no machine-readable contract and no public API
reference. There is no OpenAPI, Swagger, AsyncAPI, GraphQL SDL, WSDL or Postman
collection at any reachable URL. The reference material sits inside two
password-protected ReadMe hubs, and access is granted only after a Developer Access
Request form is approved. An agent cannot integrate with Jifiti from public
information alone; it must first obtain portal credentials from Jifiti.

## APIs

- [Jifiti Buy Now Pay Later API](https://www.jifiti.com/api/): Split payments and
  consumer financing for merchants — one-time loans and revolving lines of credit,
  plus embeddable promotional widgets. Reference is gated.
- [Jifiti Embedded Lending API](https://www.jifiti.com/lending-api/): For banks and
  lenders — platform architecture, component diagrams and integration guides for
  mapping a lending solution onto Jifiti. Reference is gated.
